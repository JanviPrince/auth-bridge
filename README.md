# Auth Bridge — Week 4: Connect Frontend & Backend

A full-stack authentication system built with React.js and Node.js as part of the MERN Stack internship Week 4 task.

## Task Requirements ✅
- Signup form integrated with backend API
- User data stored in database
- Login form integrated with backend API
- Credentials verified from database
- Fetch API used for frontend-backend communication
- Success and error messages displayed from API response

## Tech Stack
- **Frontend:** React.js, Tailwind CSS, TypeScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (JSON emulator for local development)
- **Tools:** Vite, VS Code, Git

## Features
- User registration with form validation
- Password hashing using SHA-256
- JWT-style session token generation
- Login with email or username
- Live API request logger
- Real-time database viewer
- Session persistence using localStorage
